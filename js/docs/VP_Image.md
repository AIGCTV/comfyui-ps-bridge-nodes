# PS Images

选择 main、IMG2–IMG6，图中名称必须唯一。输出依次 RGB、ALPHA、MASK、width、height。main 有真实选区时 MASK 为选区，否则全白；参考图始终全白 MASK。ALPHA：1不透明、0透明。点击＋上传本地图片。桥接运行的图片与选区来自当前鉴权绑定，不读取最近一次图片。

本地换图：＋上传成功后解除旧选区绑定；取消或失败不改变原配置。已有工作流的本地选区配置在保存重开后继续保留。没有配置选区时全白；已指定却丢失/尺寸错误的选区会明确报错。仅使用图像时只连接 RGB，MASK 不会自动作用于图像，ALPHA 也不会自动转为选区。

类别：🔷PS Vplugins。旧版节点 ID 或输出端口布局不兼容，不自动迁移。当前六节点中多余的参数输入端口会按定义移除；如果已有错误参数连线，会提示核对当前参数值，正常输出连线保持不变。

经典画布中，顶部是名称选择与上传按钮，预览铺满下方可用区域并保留图片比例；五个原生输出口透明叠加在预览右上侧。预览与节点一起绘制、移动和遮挡，点击预览空白可拖动整个节点。本地图片会应用 EXIF 方向，支持静态调色板 PNG 和灰度透明图片；选区必须匹配规范化后的尺寸。高位深和动画仍会拒绝。Vue Nodes 暂不支持此自定义上传/预览布局。
